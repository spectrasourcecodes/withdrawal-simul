# 🏦 BancoSim · Simulação de Saque Bancário

Uma aplicação frontend moderna que simula o fluxo completo de um saque bancário digital no estilo Brazilian Fintech.

## ✨ Funcionalidades

- Fluxo de saque em 4 etapas: Método → Dados Bancários → Verificação KYC → Análise
- Interface limpa, premium e responsiva (Tailwind CSS)
- Validação de formulários com mensagens de erro claras
- Context API para gerenciamento de estado
- Simulação de loading na verificação KYC
- Indicador de progresso visual
- Componentes reutilizáveis e arquitetura limpa

## 🚀 Tecnologias

- React 18 (JSX, Hooks)
- Vite (build tool)
- Tailwind CSS 3 (estilização)
- React Router 6 (navegação)
- Context API (estado global)
